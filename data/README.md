# Data

Public-domain texts from Project Gutenberg (Jane Austen, 1811-1817), obtained via the
`nltk_data` Gutenberg corpus mirror. They are used only to train the toy n-gram language
model (`data/corpus/`) and as a held-out pool of human-written text for null calibration,
dilution attacks and prompts (`data/human/`). No copyrighted material is included.
